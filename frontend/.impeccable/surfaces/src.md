# Vision Lab app (all routes)

Mode: Operate. Audience: the team's vision lead tuning cube detection four days before the contest.
Task: upload image/video, preview pipelines live, save runs, compare, manage models/storage.
Pinned by the brief (beats the roll): neutral dark viewer surface, quiet chrome, one accent,
Pretendard, tabular numbers, dense but calm panels, 1440/1280 laptops, not broken at 1180.

## Direction contract

FORM: camera calibration target / fiducial marker sheet (grounded candidate 5). seed:de5211e46c549573

THESIS: The interface speaks the detector's own visual language. Chrome is achromatic so the only
hues on screen are the media and the cube classes; refuses the category's tinted dashboard with
coloured cards and gradient buttons.

OWN-WORLD: strictly neutral graphite ground (no blue cast, colours read true), paper-white as the
single accent (primary action, focus, selection), square corners (2 px max), 1 px hairline seams,
cube class colours R/G/B/W/? used only for data, each with a letter label. Pretendard throughout,
tabular figures, rank by weight more than size.

STORY: the visitor sees the frame large first, the cubes drawn on it, then the numbers that made it.

FIRST VIEWPORT: media rail left, the viewer owning the centre at full height minus a runs strip,
parameter panel right; the viewer shows the media with quads and a mode badge.

SIGNATURE: registration corners. Every selection is drawn the way a detection is drawn: four L-shaped
corner ticks (selected media tile, selected run, highlighted cube, drop target, media bounds in the
viewer); at high zoom the viewer shows the pixel grid like a calibration target.

RISK: an achromatic shell can read as unfinished; the corner marks, crisp seams and tight numerals
must carry the craft.

Verdicts: ikeda-datamatics declined (kept: numerals in tight tabular columns);
rw-manual-acetate-tab-board declined (kept: one fixed mark per state);
dark-first-developer-console competitive (kept: destructive actions isolated, outline until focused,
panels persist); terminal-yellow-wayfinding declined (kept: the followed selection stays marked from
rail to strip to viewer badge); rw-timetable-slide-rack declined (kept: tight scale, rank by weight);
doujin-event-catalog declined (kept: dense real thumbnails as the navigation handle).
